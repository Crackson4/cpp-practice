# Network Programming

We are learning network programming in order to create a trojan virus. This virus, when run on the victim's computer, will send the victim's discord token to us. We can then use this token to steal their discord account.

This exercise is for practice **only**. Any malware that is created will not be used for any nefarious purposes.

## Steps to Success

- [x] Choose a language to code in and compile to a .exe file
- [x] Program the server and client
- [ ] Make a Discord token logger to access the victim's Discord account
- [ ] Make a file accessor (Which may aid in creating the token logger)
